# PirateSky ☠️

Bluesky, but pirates.

An [atproto](https://atproto.com) app view that logs into yer Bluesky account and renders yer timeline entirely in pirate: every post translated to pirate speak, every scallywag given a pirate rank, every avatar fitted with a tricorn hat, or bandana all wrapped in a parchment-and-wood theme.

## Runnin' the ship

```sh
npm install
npm run dev
```

Then open the printed localhost URL and sign in with yer Bluesky handle and an [app password](https://bsky.app/settings/app-passwords) — ne'er yer main password. Credentials go straight to `bsky.social` and nowhere else; the session be stored in yer browser's localStorage.
